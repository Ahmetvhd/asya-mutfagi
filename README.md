# 🍜 Asya Mutfağı (Asian Kitchen)

Asya mutfağının en popüler lezzetlerini bir araya getiren, kullanıcı dostu ve interaktif bir menü projesidir. Bu çalışma, modern web geliştirme teknikleri kullanılarak hazırlanmıştır.

---

## ✨ Özellikler

* **Dinamik Filtreleme:** Mutfak türlerine (Kore, Japonya, Çin) göre anlık yemek listeleme.
* **Detaylı Kartlar:** Her yemek için açıklama, fiyat ve görsel sunumu.
* **Responsive:** Tüm ekran boyutlarına (Mobil, Tablet, Masaüstü) uyumlu tasarım.

## 🛠️ Teknolojiler

* **HTML5**
* **CSS3** (Bootstrap 5)
* **JavaScript** (ES6+ Array metotları)
